# Linearr — Personas

> Who uses this product. Every user journey, user flow, and use case should
> name which persona it's for.

## Persona template

Copy this block per persona.

### <Persona name — e.g. "Ops Manager Olivia">

- **Role / title:**
- **Goals:** _What is this persona trying to accomplish with the product?_
- **Pain points:** _What's frustrating or blocking them today?_
- **Technical fluency:** _Novice / intermediate / power user._
- **Context of use:** _Device (desktop/mobile/tablet), environment (office,
  field, on-call), frequency (daily, weekly, one-off)._
- **Success looks like:** _What does "this product worked for me" mean to
  this persona specifically?_

---

## Primary personas

_The 1-3 personas the product is designed around._

## Secondary personas

_Personas who use the product but aren't the primary design target — don't
skip them, but don't over-index on them either._

## Anti-personas

_Optional but useful: who this product is explicitly NOT for, and why. Keeps
scope honest when a feature request comes from outside the target
audience._
