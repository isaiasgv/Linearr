# Linearr — MVP Definition

> The smallest slice that delivers real value and lets you learn something
> — not "everything minus polish". Explicitly separate what ships now from
> what's deferred from what's rejected, so scope creep has something to
> point at.

## Core value proposition

_In one sentence: what value does the MVP deliver, to whom?_

## What's IN the MVP

_The minimum feature set that delivers the core value proposition above.

IDs._

## Success criteria for the MVP

_How will we know the MVP validated (or invalidated) the core value
proposition? Tie to measurable signals, not just "ship it and see"._
