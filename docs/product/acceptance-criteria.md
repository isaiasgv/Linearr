# Linearr — Acceptance Criteria

> The testable definition of "done" for a requirement or user story, in
> Given/When/Then form. Every functional requirement that ships should have
> at least one acceptance criterion; every acceptance criterion should be
> traceable to a test.

## Acceptance criteria template

Copy this block per requirement/story.

### AC for <FR-# or story name>

```
Given <initial context/state>
When <action the user or system takes>
Then <expected observable outcome>
```

_Add more Given/When/Then blocks for alternate/edge cases of the same
requirement rather than cramming them into one._
