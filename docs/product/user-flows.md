# Linearr — User Flows

> The concrete, in-app step sequence for ONE task ("reset password",
> "checkout"). Narrow, screen-by-screen, testable. For the broader
> cross-session narrative, see [user-journeys.md](./user-journeys.md); for
> a flow with meaningful branching, promote it to
> [use-cases.md](./use-cases.md) instead.

## Flow template

**Steps:**

1. User: <action> → System: <response>
2. User: <action> → System: <response>
3. …

- **Success state:** _what does the user see/get on completion?_

  state if they do?_
